# Рекомендації AI: методика версії 2

Впізнавання бренду і рекомендації вимірюються окремо. Ніша та географія беруться з форми або визначаються автоматично. Для точної перевірки домену можна вказати необов'язковий сайт.

## Вибірка і докази

За замовчуванням перевіряємо 3 однакові для всіх систем нішеві запити без назви цільового бренду. Кожен запит надсилається ChatGPT, Claude, Gemini та Perplexity через чинні API-інтеграції. Відповіді зберігаються окремо: AI, модель, режим пошуку, текст, дата та точний запит.

Один додатковий виклик Claude на запит розбирає вже отримані відповіді, без пошуку конкурентів в інтернеті. Для кожної компанії потрібні назва, тип згадки та дослівна неперервна цитата. Код звіряє цитату з відповіддю, назву з цитатою та домен із цитатою. Вигаданий домен або непідтверджена цитата роблять класифікацію недоступною, а не нульовою.

Це автоматична класифікація, а не гарантія істинності тверджень моделей. Неоднозначні назви/транслітерація можуть вимагати уточнення. Відповіді API не тотожні персоналізованим відповідям у споживчих застосунках. Claude працює без пошуку; для інших режим фіксується за конфігурацією і не гарантує, що модель застосувала інструмент у кожній відповіді.

## Оцінки

Для кожної AI:

- Бренд: частка успішно класифікованих запитів, де є позитивна рекомендація назви.
- Сайт: частка таких запитів, де рекомендовано саме вказаний домен (www нормалізується). Саме посилання-джерело не рахується.
- Бренд або сайт: частка запитів з хоча б одним із цих сигналів; подвійного рахування немає.
- 2 рекомендації з 3 успішних відповідей = 67/100. Кожен запит має однакову вагу.
- Помилки провайдера/класифікації виключені зі знаменника; кількість відсутніх відповідей показана.
- Без успішних відповідей бал null, «немає даних». Без домену оцінка сайту null, «не вказано».

Загальний бал рекомендацій: рекомендації / усі успішні пари AI × запит. Загальний AI-visibility score: середнє бала рекомендацій і впізнавання; якщо одна компонента недоступна, показуємо іншу. Впізнавання: know=100, confused=50, unknown=0; помилки виключені.

## Конкуренти

Перелік складається виключно з позитивних рекомендацій у фактичних відповідях. Для кожного конкурента наведено AI, запит та цитату. «Замість вас» означає відсутність рекомендації цільового бренду/сайту в цій відповіді; «поряд із вами» - обидва рекомендовані. Це не підтвердження якості компаній і не рейтинг ринку. Порожній перелік не означає вільної ніші.

## Доставка і сумісність

Нові поля API зворотно сумісні: `recommendations`, у `reportSummary` короткий список балів усіх чотирьох AI. Чинний SendPulse блок `{{$['reportSummary']}}` підхоплює їх без нового налаштування. Деталі й окремі бали бренду/домену містяться в PDF.

Новий аналіз застосовується до нових сканувань. Збережені PDF не перебудовуються. Старі записи без класифікації не перетворюються на рекомендації. На сторінці результату, як і раніше, немає балів: тільки вміст звіту й Telegram CTA.

Постійна БД не активована за рішенням користувача. Звіти зберігаються в тимчасовій пам'яті. Вдалий аналіз відповіді може кешуватись на 24 години; у PDF збережено його дату, кеш позначено.
