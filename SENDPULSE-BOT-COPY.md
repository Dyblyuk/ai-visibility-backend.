# Top Marketing · Оновлення Telegram-бота

Готові тексти для чинного ланцюжка видачі AI-звіту. Сервер не змінює блоки SendPulse автоматично.

## 1. Перше повідомлення — перед запитом контакту

**Ваш звіт AI-видимості готовий**

Ми зібрали результати перевірки вашого бренду в ChatGPT, Claude, Gemini та Perplexity.

У PDF ви знайдете:
• оцінку AI-видимості бренду;
• відповіді кожної системи;
• згадки бренду та конкурентів у перевірених запитах;
• рекомендації й наступні кроки.

**Щоб отримати звіт, поділіться номером телефону через кнопку нижче.** Після цього бот надішле ваш PDF у цей чат.

Кнопка введення контакту: **Поділитися контактом і отримати звіт**.
Тип: Phone or Contact; тільки через Share Contact; змінна `Phone`.
Зелений вихід → API. Червоний вихід таймера → нагадування, а не API.

## 2. API — додаткові відповідності

Чинні `score`, `brand`, `tier`, `pdfUrl` залишити. Нові змінні створити з типом «Рядок».

| Поле відповіді | Змінна SendPulse |
|---|---|
| `{{$['reportSummary']}}` | `reportSummary` |
| `{{$['reportGuide']}}` | `reportGuide` |
| `{{$['tier']}}` | `tier` |

У повідомленні відразу після успішного API вставити **тільки**:

```
{{reportSummary}}
```

Сервер сам підставить бренд, бал, категорію та коротке пояснення залежно від бала. Динамічний текст краще надсилати як звичайний текст без Markdown-парсингу назв брендів.

## 3. Повідомлення з файлом

**Ваш PDF-звіт**

Збережіть файл, щоб повернутися до результатів і рекомендацій у зручний час.

До цього повідомлення додати блок «Файл»: `{{pdfUrl}}`.

## 4. Як читати результат

Після файла — окреме повідомлення:

```
{{reportGuide}}
```

За бажанням додати звичайну кнопку **Розібрати звіт**. Вона веде до короткого запитання:

**На чому хочете зосередитися?**

Напишіть, що для вас зараз важливіше: щоб AI правильно описував бренд, частіше рекомендував вас або допомагав залучати нові звернення.

Після відповіді — передати чат менеджеру; не обіцяти конкретного часу відповіді без узгодженого графіка.

## 5. Якщо людина не поділилася контактом

Ваш звіт можна отримати після передачі контакту. Коли буде зручно, поверніться до кнопки «Поділитися контактом і отримати звіт».

Не підключати цей вихід напряму до API чи файла.

## 6. Якщо API повернув помилку

**Не вдалося завантажити звіт**

Спробуйте ще раз за хвилину. Якщо ви відкрили бот без переходу з аналізатора, поверніться на сайт і натисніть кнопку отримання звіту.

Кнопка **Повторити** → той самий API-блок.
Кнопка-посилання **Перейти до аналізатора** → https://services.topmarketing.com.ua/

## Візуальний формат

Один змістовий блок — одне повідомлення. Короткий жирний заголовок, порожній рядок між абзацами, до чотирьох пунктів у списку. Не робити текст із десятків емодзі та не дублювати бал кількома повідомленнями.

Шрифт і колір бульбашок визначає Telegram користувача. Фірмовий стиль зберігають логотип бота, тон повідомлень і оформлення PDF; довільні CSS-шрифти та помаранчеві кнопки у звичайних повідомленнях Telegram не задаються.

## Перевірка

Зберегти зміни блоків і всього ланцюжка. Пройти зі свіжого аналізу. Перевірити: до контакту PDF не надсилається; після контакту є бренд, бал, рівень, PDF та інструкція. Вихід помилки не веде до порожнього результату.
