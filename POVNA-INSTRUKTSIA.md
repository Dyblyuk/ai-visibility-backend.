# AI-Visibility Scanner — повна інструкція з підключення

Весь шлях від файлів, які я вам віддав, до робочого інструменту на вашому
сайті. Виконуйте по порядку — кожен крок спирається на попередній.

**Що вийде в результаті:** бекенд на Render, який реально опитує ChatGPT,
Gemini, Perplexity і Claude; фронтенд-сторінка, яка до нього звертається;
ліди з форми "отримати повний звіт" падають у вашу Google Таблицю.

## Крок 1. Отримайте API-ключі

Знадобиться 4 ключі. Кожен — окрема реєстрація, у більшості потрібна карта
для верифікації (але є безкоштовні ліміти):

| Система | Де отримати ключ |
|---|---|
| OpenAI (ChatGPT) | platform.openai.com → API keys → Create new secret key |
| Google (Gemini) | aistudio.google.com/app/apikey → Create API key |
| Perplexity | perplexity.ai/settings/api → Generate |
| Anthropic (Claude) | console.anthropic.com → Settings → API Keys → Create Key |

Збережіть усі 4 кудись тимчасово (текстовий файл на компʼютері) — вони
знадобляться в кроці 3. Не вставляйте їх у код і не публікуйте ніде.

Можна почати і не з усіма чотирма — сканер покаже помилку лише по тій
системі, чийого ключа немає, решта працюватимуть.

## Крок 2. Заливаєте код бекенду на GitHub

У папці `ai-visibility-backend` (яку я вам віддав) відкрийте термінал.

1. Створіть новий репозиторій на github.com → **New repository** → назва,
   наприклад `ai-visibility-backend` → нічого не позначайте в
   "Initialize this repository with" → **Create repository**.
2. GitHub покаже URL репозиторію — скопіюйте його.
3. У терміналі:
   ```bash
   git init
   git add .
   git commit -m "AI-visibility backend"
   git branch -M main
   git remote add origin https://github.com/ВАШ-ЛОГІН/ai-visibility-backend.git
   git push -u origin main
   ```
4. Якщо це перший push з цього компʼютера — Git попросить авторизуватись
   через браузер, це нормально, пройдіть.
5. Перевірка: оновіть сторінку репозиторію на github.com — має зʼявитись
   список файлів (`server.js`, `package.json`, `README.md`...). Файлу `.env`
   там **не повинно бути** (він у `.gitignore`).

## Крок 3. Розгортаєте на Render

1. render.com → **New** → **Web Service**.
2. **Build and deploy from a Git repository** → якщо GitHub ще не
   підключено, натисніть **Connect account** і авторизуйте.
3. Оберіть репозиторій `ai-visibility-backend` → **Connect**.
4. Заповніть:

   | Поле | Значення |
   |---|---|
   | Name | будь-яке, напр. `ai-visibility-backend` |
   | Region | найближчий до вас |
   | Branch | `main` |
   | Root Directory | залиште порожнім |
   | Runtime | `Node` |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | Free (для старту) |

5. Прокрутіть до **Environment Variables** → **Add Environment Variable**,
   додайте по одному (значення — ваші ключі з кроку 1):

   ```
   OPENAI_API_KEY       = sk-...
   GEMINI_API_KEY        = AIza...
   PERPLEXITY_API_KEY    = pplx-...
   ANTHROPIC_API_KEY     = sk-ant-...
   CLAUDE_MODEL          = claude-sonnet-5
   DISCOVERY_QUERY_COUNT = 3
   DISCOVERY_ENGINES     = chatgpt,gemini,perplexity,claude
   ```

   `LEAD_WEBHOOK_URL` поки залиште порожнім — впишете у кроці 5.

6. **Create Web Service**. Зачекайте кілька хвилин, поки Render зробить
   `npm install` і запустить сервер (прогрес видно в логах на екрані).
7. Після завершення вгорі зʼявиться URL типу:
   ```
   https://ai-visibility-backend.onrender.com
   ```
   Збережіть його — знадобиться в кроках 5 і 6.

## Крок 4. Перевірте, що ключі підхопились

Відкрийте в браузері:
```
https://ai-visibility-backend.onrender.com/api/health
```

Має показати:
```json
{"ok":true,"keys":{"openai":true,"gemini":true,"perplexity":true,"anthropic":true}}
```

Якщо якийсь `false` — перевірте, чи правильно вписаний відповідний ключ у
Environment Variables на Render (без зайвих пробілів на початку/в кінці).

## Крок 5. Підключіть Google Таблицю для лідів

1. sheets.new → створиться нова порожня таблиця.
2. У ній: **Розширення → Apps Script**.
3. Видаліть весь код-заглушку в редакторі, вставте замість нього повний
   вміст файлу `google-sheets-webhook.gs` (я вам його віддав).
4. Значок дискети — зберегти.
5. **Розгорнути** (Deploy) → **Нове розгортання** (New deployment) →
   шестерня біля "Тип" → **Веб-застосунок** (Web app).
6. Заповніть:
   - Execute as: **Me**
   - Who has access: **Anyone**
7. **Розгорнути**. Google попросить дозволи — підтвердіть (може зʼявитись
   попередження "Google не перевірив цей додаток" — це нормально для
   власних скриптів: **Додатково → Перейти (незахищена сторінка)**).
8. Скопіюйте URL веб-застосунку:
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```
9. Поверніться на Render → ваш сервіс → Environment → додайте:
   ```
   LEAD_WEBHOOK_URL = https://script.google.com/macros/s/AKfycb.../exec
   ```
   Збережіть — Render сам передеплоїть сервіс.

Детальніше з поясненнями кожного пункту — у `GOOGLE-SHEETS-SETUP.md`.

## Крок 6. Підключіть фронтенд

Відкрийте файл `ai-visibility-scanner.html`, знайдіть на початку `<script>`:

```js
const API_URL = '';
```

Впишіть туди URL бекенду з кроку 3, **додавши в кінці `/api/scan`**:

```js
const API_URL = 'https://ai-visibility-backend.onrender.com/api/scan';
```

Збережіть файл.

## Крок 7. Наскрізна перевірка

1. Відкрийте `ai-visibility-scanner.html` у браузері.
2. Під формою має зʼявитись напис "Режим: **реальна перевірка**" (не
   "демо") — це означає, що `API_URL` підхопився.
3. Введіть назву бренду і нішу, натисніть "Запустити скан →".
4. Перше сканування на безкоштовному плані Render може зайняти 20–50
   секунд (сервіс "прокидається" зі сну) — це очікувано.
5. Мають з'явитись реальні "ЗГАДУЄ / НЕ ЗГАДУЄ" по кожній системі і блок
   "Зона невидимості".
6. Прокрутіть до форми "Отримати повний звіт", заповніть тестовими даними,
   надішліть.
7. Відкрийте вашу Google Таблицю → аркуш "Ліди" → має з'явитись новий
   рядок з тестовими даними.

Якщо все з'явилось — інструмент повністю підключений.

## Якщо щось не працює

| Симптом | Що перевірити |
|---|---|
| "Режим: демо" не зникає | `API_URL` в HTML-файлі порожній або з друкарською помилкою |
| Скан довго висить і падає в демо-режим | Render ще "прокидається" (перший запит після сну) — спробуйте ще раз через хвилину |
| `/api/health` показує `false` по якомусь ключу | Помилка в назві змінної або самому ключі на Render |
| Лід не долітає в таблицю | `LEAD_WEBHOOK_URL` не збережений на Render, або в Apps Script при розгортанні обрали не "Anyone" |
| Конкретна система стабільно "НЕДОСТУПНО" | Дивіться Logs вашого сервісу на Render — там текст помилки від відповідного API |
